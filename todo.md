# 📋 План реализации: Screen Dreams

## Описание проекта
Сайт с коллекцией интерактивных скринсейверов для размещения на GitHub Pages. Пользователь может выбрать интересующий скринсейвер из галереи и запустить его на полный экран.

---

## 🎯 Технические решения

| Параметр | Решение |
|----------|---------|
| Платформа | GitHub Pages (статичный HTML) |
| Превью | Статичные картинки (PNG) |
| Навигация | Кнопка "Назад" + клавиша Escape |
| Полноэкранный режим | Кнопка "Полный экран" |
| Фон главной страницы | Тёмная тема (разные оттенки) |
| Анимация карточек | Увеличение при наведении |
| Расширяемость | JSON-конфиг + шаблон |

---

## 🎨 Список скринсейверов (7 штук)

| # | Название | Описание | Технология | Файл |
|---|----------|----------|------------|------|
| 1 | Matrix | Зелёные символы падают вниз | Canvas 2D | screensavers/matrix/ |
| 2 | Particles | Интерактивные частицы, следующие за мышью | Canvas 2D | screensavers/particles/ |
| 3 | Starfield | 3D полёт сквозь звёзды | Three.js (WebGL) | screensavers/starfield/ |
| 4 | Snow | Мягко падающий снег | Canvas 2D | screensavers/snow/ |
| 5 | Rain | Вертикальный дождь с размытием | Canvas 2D | screensavers/rain/ |
| 6 | Gradient | Плавно меняющиеся градиенты | CSS | screensavers/gradient/ |
| 7 | Fire | Реалистичное пламя | Canvas 2D | screensavers/fire/ |

## 📝 Как добавить новый скринсейвер

1. Скопируйте папку `screensavers/_template`
2. Переименуйте её (например, `my-new-screensaver`)
3. Отредактируйте `script.js` с вашей анимацией
4. Создайте превью и сохраните в `images/previews/`
5. Добавьте запись в `data/screensavers.json`
6. Сделайте коммит и запушьте!
