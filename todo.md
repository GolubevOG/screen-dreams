# 📋 План реализации: Screen Dreams

## Описание проекта
Сайт с коллекцией интерактивных скринсейверов для размещения на GitHub Pages. Пользователь может выбрать интересующий скринсейвер из галереи и запустить его на полный экран.

---

## 🎯 Технические решения

| Параметр | Решение |
|----------|---------|
| Платформа | GitHub Pages (статичный HTML) |
| Превью | Динамичные Canvas-анимации при наведении (15fps) |
| Навигация | Кнопка "Назад" + клавиша Escape |
| Полноэкранный режим | Кнопка "Полный экран" |
| Фон главной страницы | Тёмная тема |
| Анимация карточек | Увеличение при наведении |
| Расширяемость | JSON-конфиг + шаблон |
| Фильтры | 5 категорий (Космос, Природа, Абстракция, Часы, Интерактив) |
| Поиск | По названию с debounce 300ms |
| Сортировка | По имени, технологии |
| Избранное | Кнопка ❤️ + localStorage |
| Tooltips | Всплывающие подсказки при наведении |
| Состояние | Сохранение фильтров, поиска, позиции скролла в localStorage |

## 📝 Как добавить новый скринсейвер

1. Скопируйте папку `screensavers/_template`
2. Переименуйте её
3. Отредактируйте `script.js` с анимацией
4. Добавьте запись в `data/screensavers.json`
5. Добавьте мини-анимацию в `js/gallery.js`
6. Сделайте коммит и запушьте!

## 🔧 ПЛАН ИСПРАВЛЕНИЙ (по результатам аудита кода)

Каждый пункт = отдельный коммит.

### 🔴 Баги

- [x] **Firework** — битая альфа: `.replace('rgb','rgba')` не работает на hex-цветах, следы/частицы исчезают резко (`script.js:42,83`); `setInterval` спавнит фейерверки при скрытой вкладке, массив растёт (`script.js:92`)
- [x] **Ripple** — та же битая альфа на hex (`script.js:33`); `setInterval` без очистки, массив растёт при скрытой вкладке (`script.js:53`)
- [x] **Галерея** — утечка rAF: при ре-рендере галереи `mouseleave` не срабатывает на удалённых карточках, анимация превью вечно рисует в отсоединённый canvas (`js/gallery.js`)
- [x] **Circle** — двойное центрирование (`translate(-50%)` + отрицательные margin), кольца не концентричны (`index.html:25,41-46`)
- [x] **Maze** — `resize()` меняет размер canvas, но не переинициализирует сетку лабиринта (`script.js:4-9`)
- [x] **Resize-баги состояния** — matrix, retro, neon, pendulum, gravityclock, orbitclock: состояние посчитано один раз от стартового размера окна, после resize композиция разъезжается

### 🟠 Производительность

- [x] **Galaxy** — 4000 отдельных `THREE.Points` = 4000 draw calls → слить в один `BufferGeometry` с `vertexColors` (`script.js:30-55`)
- [x] **Галерея** — 12 iframe-превью продолжают анимироваться вне вьюпорта → пауза через IntersectionObserver
- [x] **Particles** — O(n²): ~20 000 проверок дистанций/кадр при 200 частицах + аллокация строки на каждую линию (`script.js:63-75`)
- [x] **Plasma** — `createImageData` каждый кадр вместо переиспользуемого буфера + ~130k аллокаций `hslToRgb` (`script.js:36,49`)
- [x] **Waterfall** — до 150 `createLinearGradient` на каплю каждый кадр → кэш градиентов (`script.js:55-58,86-89`)
- [x] **Кэш градиентов** — bubbles (×50/кадр), fireflies (×50/кадр), crystal (×8/кадр), ocean, waves — создавать один раз
- [x] **Particles/соединения** — снизить частоту проверок связей (кадр через один)

### 🟡 Мелочи

- [x] **PixelClock** — пересоздание 280 div каждую секунду → переключение классов у существующих (`index.html:253-262`)
- [x] **AnalogClock** — `setInterval(updateClock, 50)` → requestAnimationFrame (`index.html:243`)
- [x] **Matrix** — мёртвая работа: градиент перекрывается сплошным `#0f0` (`script.js:38-50`); `setInterval(33)` → rAF (`script.js:69`)
- [x] **Pendulum** — физика зависит от FPS: damping 0.999/кадр, маятник останавливается за минуту → dt-нормализация (`script.js:16-27`)
- [x] **style.css** — дубли `.card__info`, `.card__name` (строки 218-227 vs 326-339)
- [x] **gallery.js** — объект `previewFunctions` из 35 функций пересоздаётся на каждый hover → вынести на уровень модуля (`js/gallery.js:395-431`)
